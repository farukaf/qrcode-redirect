# QR Code Redirect

Create a QR code for a temporary redirect. Scan the code, choose a destination, and redirect visitors from the displayed QR code.

Built with [Blazor](https://dotnet.microsoft.com/apps/aspnet/web-apps/blazor) on ASP.NET Core. The application does not require an external database.

## Run with Docker

```sh
docker run --rm -p 8080:8080 farukaf/qrcode-redirect:latest
```

Open [http://localhost:8080](http://localhost:8080) in your browser. The application is available as a [Docker Hub image](https://hub.docker.com/r/farukaf/qrcode-redirect).
